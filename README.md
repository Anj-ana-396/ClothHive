
# Clothing E-Commerce Website with Admin Panel

<img width="1920" height="1200" alt="Screenshot (127)" src="https://github.com/user-attachments/assets/bf5bad03-2d2b-491c-805e-43812eb5f753" />


A full-stack MERN (MongoDB, Express.js, React.js, Node.js) based Clothing E-Commerce application with a secure Admin Panel for managing products, users, and orders.
### User Features
- User Registration & Login
- JWT Authentication
- Browse Clothing Products
- Search & Filter Products
- Product Details Page
- Add to Cart
- Remove from Cart
- Quantity Management
- Checkout Page
- Responsive Design

### Admin Features
- Admin Login
- Add New Products
- Edit Products
- Delete Products
- Manage Orders
- Update Order Status
- Manage Users
- Product Image Upload



## Installation

### Clone Repository
```bash
git clone https://github.com/Anj-ana-396/ClothHive
cd ClothHive
```

### Install Frontend Dependencies
```bash
cd frontend
npm install
```

### Install Backend Dependencies
```bash
cd backend
npm install
```

##  Environment Variables
Create a `.env` file inside the server folder:
```env
PORT=5000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_API_KEY=your_api_key

CLOUDINARY_API_SECRET=your_api_secret
```

##  Running the Project
### Start Backend

```bash
npm run dev
```
### Start Frontend

```bash
npm run dev
```
